# Reflections

1. Share one aspect of building this project you found challenging and how you
   overcame it.

One aspect of building this project that I found challenging was testing. Testing is something I've really dived into because of this project. At first, I struggled with understanding how to properly test functions that require user input, especially when those functions depend on other functions. I had to learn how to use mocking to simulate user input and test different outcomes without manually running the program every time. Through trial and error, researching errors, and breaking down how my functions interacted, I became more comfortable writing tests and troubleshooting failures.

2. Share one technical concept that you gained a deeper understanding of
   through building this project. Explain that concept in simple terms and
   explain how it is used in your project.

One technical concept I gained a deeper understanding of was loops and how they control program flow. Before this project, I understood the basic purpose of loops, but I didn't fully understand how continue affected them. I learned that continue skips the rest of the current iteration and starts the next one. I used these concepts in my Rock Paper Scissors game to allow players to retry invalid inputs, replay tied rounds, and keep the main menu running until the user chooses to exit.
